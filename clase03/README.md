# Generación y Análisis de Ondas

Esta clase presenta una serie de ejercicios prácticos orientados a la **generación, cuantización y análisis de señales** utilizando Python.  
El objetivo general es comprender las características de las distintas formas de onda y su representación tanto en el dominio del tiempo como en el dominio de la frecuencia.

---

## 🧩 Ejercicio 5 – Generación de la onda y cuantización
En este ejercicio se genera una señal periódica y se analiza su **cuantización**, observando cómo la resolución afecta la forma de la onda.  
Se emplean funciones de Python para crear la señal y graficarla, comparando versiones con distintos niveles de cuantización.

---

## ⚙️ Código de prueba de ejemplo
Se incluye un bloque de código base provisto por el docente para verificar el correcto funcionamiento del entorno y las funciones de generación de señales.

---

## 🎵 Ejercicio 6 – Generación de señales y análisis espectral
Este ejercicio amplía los conceptos del anterior, incorporando el análisis de las señales generadas mediante el uso de transformadas y representaciones en frecuencia.  
El objetivo es **visualizar el espectro** y comprender la relación entre el dominio temporal y el frecuencial.

---

## 🎹 Piano 440 Hz – Tono puro
Se analiza una señal real correspondiente al tono **La4 (440 Hz)**, similar al de un piano afinado.  
El análisis muestra una **onda senoidal limpia y estable**, con un solo pico en el espectro centrado en 440 Hz, correspondiente a la frecuencia fundamental.

---

## 📈 Ejercicio 7 – Análisis final
El ejercicio final integra los conceptos previos para realizar un **análisis comparativo entre distintas señales** y sus respectivas transformadas.  
Se estudia cómo cambian las características de la onda y del espectro al modificar parámetros como frecuencia o forma.
